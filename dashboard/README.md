# dashboard — 웹 대시보드 (HTML·CSS·JS, 보기 전용)

bridge가 이 폴더를 그대로 제공합니다 → `bridge/start_bridge.bat` 실행 후 `http://127.0.0.1:8000` (자동으로 열림)
빌드 도구·외부 라이브러리·인터넷 연결 없이 동작합니다.

## 이 화면으로 내리는 판단
> **"지금 AI에게 가야 하나, 계속 맡겨도 되나 — 그리고 컴퓨터와 알림 장치가 그 작업을 감당하고 있나?"**

모든 구역은 이 질문의 일부에 답합니다. 구역 제목 옆에 각 구역이 답하는 질문을 적어 두었습니다.

## 화면 구성과 참고한 사례 (대시보드 디자인 사례 20선)

| 구역 | 답하는 질문 | 내용 | 적용한 원칙 |
|---|---|---|---|
| **AI 작업** | 지금 가야 하나? | 상태(아이콘+글자), 진행도 큰 숫자, 단계 5칸, 경과·소요 시간, "지금 할 일", 현재 작업 진행 기록 | **C18 Uptime Kuma** 현재 상태와 최근 사건을 함께 · **C09** 요약 → 설명 순서 |
| **컴퓨터 상태** | PC가 감당하고 있나? | 종합 부하, CPU 사용량·온도·메모리·배터리 타일, 최근 10분 그래프 2개 | **C07 Grafana Node Exporter** 같은 종류 지표는 같은 카드 규칙, 핵심만 · **C10 CloudWatch** 함께 읽을 지표를 한 구역에 |
| **알림 장치** | 장치가 제대로 붙어 있나? | UNO(연결·LCD 재현·마지막 버튼), 웹캠(화면·인식 결과·유지 시간·미리보기), ESP32-S3(칩 온도·Wi-Fi·수신 간격) | **C01 Home Assistant** 장치별 카드, 조작 옆에 결과 문구 · **C18** 온라인/끊김 |
| **작업 기록** | 오늘 얼마나 맡겼고 얼마나 빨리 반응했나? | 오늘 요약 4개, 최근 작업 20건 표 | **C14** 현재·누적 구별 · **C16** 카드마다 질문 하나 |

## 파일

| 파일 | 역할 |
|---|---|
| `index.html` | 화면 구조 (시맨틱 태그, 본문 바로가기, 아이콘 모음) |
| `css/tokens.css` | 색·글꼴 변수. 라이트/다크 각각 지정 (자동 반전 아님) |
| `css/style.css` | 레이아웃, 구성요소, 좁은 화면, 움직임 줄이기, 고대비 모드 |
| `js/socket.js` | WebSocket 연결·자동 재연결 |
| `js/app.js` | 상태를 받아 각 구역 갱신, 일시정지, 테마, 웹캠 화면 |
| `js/charts.js` | SVG 선 그래프 (십자선·툴팁·키보드·표 보기) |
| `js/history.js` | 오늘 요약·최근 작업 표 |
| `js/util.js` | 시간 형식, 상태 표시 도우미 |

## 없는 데이터는 만들지 않음
- **CPU 온도**: Windows는 기본으로 알려주지 않습니다. 읽지 못하면 "측정 불가"와 해결 방법을 표시하고 그래프를 그리지 않습니다 → 아래 "CPU 온도 켜기"
- **배터리**: 데스크톱은 "배터리 없음"으로 표시합니다.
- **진행도**: 실제 진행률이 아니라 도구 사용으로 **추정**한 값이라고 화면에 적어 둡니다.
- **ESP32-S3**: 장치가 없으면 "연결된 적 없음"과 빈 값(—). 시험용 가짜 값은 "시뮬레이션 데이터" 표시가 붙습니다.
- **LCD 그림**: 실제 화면을 찍은 것이 아니라 bridge가 보낸 명령으로 재현한 것이라고 적어 둡니다.

## CPU 온도 켜기 (Windows)
1. [LibreHardwareMonitor](https://github.com/LibreHardwareMonitor/LibreHardwareMonitor/releases) 내려받아 실행 (관리자 권한 권장)
2. 메뉴 **Options → Remote Web Server → Run** 켜기 (기본 포트 8085)
3. 대시보드의 CPU 온도 타일에 `LibreHardwareMonitor · CPU Package` 같은 출처가 표시되면 성공 (최대 1분)

## 상태 기준

| 항목 | 주의 | 높음 |
|---|---|---|
| CPU 사용량 | 75% | 90% (30초 이상 지속되면 과부하) |
| CPU 온도 | 80°C | 90°C |
| 메모리 | 80% | 90% |
| 배터리 (충전기 미연결 시) | 30% 이하 | 15% 이하 |

기준값은 `bridge/system_monitor.py` 맨 위에서 바꿀 수 있습니다.
