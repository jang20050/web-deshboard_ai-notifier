# data — 실행 기록 저장소

bridge가 실행되면 이 폴더에 `notifier.db`(SQLite)가 자동으로 만들어집니다. **직접 넣을 파일은 없습니다.**
기록에는 개인 사용 패턴이 담기므로 Git에 올리지 않습니다(`.gitignore`에 포함).

## 저장되는 표

| 표 | 내용 |
|---|---|
| `tasks` | 작업 ID, 시작 시각, 종료 시각, 최종 상태(DONE/ERROR) |
| `events` | 시각, hook 이벤트 이름, 도구 이름, 계산된 단계·진행도 |
| `alerts` | 알림 종류(INPUT/DONE/ERROR), 알림 시각, 확인 시각, 확인 방법(제스처/버튼/원격), 부저 울린 횟수 |

## 저장하지 않는 것
웹캠 영상·사진, 프롬프트·파일 내용
