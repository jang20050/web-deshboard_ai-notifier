## 사용성 목표 예시 (ISO 9241-11)
- **효과성:** 대시보드·장치를 보고 현재 상태를 10번 중 10번 맞힘
- **효율성:** 알림 후 확인까지 평균 30초 이내(자리에 있을 때), 대시보드에서 상태 파악 3초 이내
- **만족도:** SUS 설문 80점 이상, 부저가 거슬렸는지 기록

## 대화 원칙 점검 (ISO 9241-110)
