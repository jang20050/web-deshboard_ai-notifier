# arduino/notifier — UNO 스케치

UNO는 **판단하지 않고 표시만** 합니다. 무엇을 보여줄지는 bridge(Python)가 정해서 시리얼로 보냅니다.
그래서 아두이노 코드는 단순하게 유지되고, 규칙을 바꿀 때는 Python만 고치면 됩니다.

> 아두이노 IDE 규칙: `.ino` 파일 이름과 폴더 이름이 같아야 합니다. → `notifier/notifier.ino`

## 넣을 파일

| 파일 | 역할 |
|---|---|
| `notifier.ino` | `setup()`·`loop()`, 시리얼 명령 처리, 버튼, LCD 화면 구성 |
| `pins.h` | 핀 번호, RGB 공통 +/− 설정 |
| `state.h` | 상태 6종 정의 |
| `display.h` / `display.cpp` | LCD1602 소프트웨어 I2C 드라이버 (라이브러리 설치 불필요), 진행 막대 |
| `light.h` / `light.cpp` | RGB 색·숨쉬기·깜빡임 (`millis()` 기반, `delay()` 없음) |
| `sound.h` / `sound.cpp` | 부저 멜로디 3종, 10회 반복 후 정지, 즉시 정지 |

추가 라이브러리 설치 없이 업로드하면 됩니다.

## 핀 배치 (실제 배선)

| 부품 | UNO 핀 | 비고 |
|---|---|---|
| LCD1602 I2C | SCL→A1, SDA→A0, 5V, GND | 하드웨어 I2C 핀(A4/A5)이 아니어서 **소프트웨어 I2C**로 구동. 주소(0x27/0x3F 등)는 자동 탐색 |
| RGB LED R / G / B | D9 / D10 / D11 | 채널마다 220Ω. 공통 +면 `pins.h`의 `RGB_COMMON_ANODE = true` |
| 수동 부저 | D7 | `tone()` 사용 |
| 확인 버튼 | D2 ↔ GND | `INPUT_PULLUP`, 누르면 LOW, 30ms 디바운스 |
| (비움) | D0, D1 | USB 시리얼 전용 |

### 알아둘 점: D11과 부저
`tone()`은 Timer2를 쓰는데, D11(파랑)의 PWM도 Timer2입니다. 소리가 날 때 D11에 밝기 값을 쓰면 **부저 음이 깨집니다.**
그래서 `light.cpp`는 소리가 나는 동안 파랑을 켜짐/꺼짐으로만 출력합니다. 소리가 나는 상태(주황·초록·빨강)는 파랑이 0이라 눈에 보이는 차이는 없습니다.
나중에 배선을 바꿀 수 있다면 파랑을 **D6**(Timer0)로 옮기면 이 제약이 사라집니다(`pins.h`만 수정).

### 알아둘 점: LCD 핀
소프트웨어 I2C라 화면 갱신이 조금 느립니다(한 글자 약 3ms, 바뀐 글자만 다시 써서 체감은 거의 없음).
SCL→A5, SDA→A4로 옮기면 하드웨어 I2C를 쓸 수 있지만, 지금 코드로도 정상 동작합니다.

## 시리얼 약속 (115200 baud, 한 줄 = 명령 하나, `\n`으로 끝)

PC → UNO

| 명령 | 예시 | 의미 |
|---|---|---|
| `S,<상태>,<%>,<문구>` | `S,WORK,55,BUILDING` | 상태·진행도·LCD 2줄 문구(16자 이내, 영문) |
| `ACK` | `ACK` | 사용자 확인 → 부저 정지, 깜빡임 멈춤 |
| `PING` | `PING` | 연결 확인 |

UNO → PC

| 응답 | 의미 |
|---|---|
| `READY` | 부팅 완료 |
| `OK` | 명령 처리 완료 |
| `PONG` | PING 응답 |
| `ERR,<이유>` | 잘못된 명령 |
| `BTN` | 확인 버튼 눌림. UNO가 **부저를 먼저 즉시 끄고** PC에 알림 → bridge가 SEEN 처리 |

LCD는 한글을 바로 표시하지 못하므로 문구는 영문 대문자로 보냅니다(한글은 대시보드에서 표시).

## 업로드와 시험
1. 아두이노 IDE에서 `notifier/notifier.ino` 열기 (같은 폴더의 .h/.cpp가 탭으로 함께 열림)
2. 보드: Arduino Uno, 포트: COM5 → 업로드
3. 시리얼 모니터(115200, 새 줄)에서 `LCD,0x27`과 `READY`가 보이면 정상 부팅
4. 시리얼 모니터를 닫고 `bridge/tools/serial_test.py` 실행 → 모든 상태를 자동으로 순서대로 시험

## 문제 해결
| 증상 | 확인할 것 |
|---|---|
| `ERR,LCD_NOT_FOUND` | SCL·SDA가 바뀌어 꽂히지 않았는지(SCL=A1, SDA=A0), LCD 5V·GND |
| `LCD,0x..`는 뜨는데 글자가 안 보임 | LCD 뒷면 파란 가변저항(대비)을 드라이버로 돌리기 |
| 색이 반대로 나옴(꺼져야 할 때 켜짐) | RGB가 공통 + → `RGB_COMMON_ANODE = true` |
| 빨강/파랑이 바뀌어 나옴 | RGB 다리 순서 확인 또는 `pins.h`의 핀 번호 교체 |
| 버튼을 안 눌렀는데 BTN | 버튼이 D2와 **GND** 사이에 있는지 (5V 아님) |

## 완료 확인
- 시리얼 모니터에서 위 명령을 직접 입력해 6개 상태가 모두 바뀌는지
- `DONE`/`INPUT`에서 부저가 10회 후 멈추는지, 중간에 `ACK`를 보내면 즉시 멈추는지
- 버튼을 누르면 PC 연결이 끊긴 상태에서도 부저가 멈추고, 연결돼 있으면 `BTN`이 한 번만 전송되는지
- 배선 사진을 `docs/wiring/`에 저장
